# Portuguese Regional Usage Notes

## Purpose

Portuguese has regional varieties. This portfolio treats Mozambican Portuguese,
European Portuguese, and Brazilian Portuguese as valid varieties.

## Important Principle

A regional difference is not automatically a grammar error. The appropriate form
depends on the target audience, context, and requested locale.

## Examples

| Concept | Brazilian Portuguese | European Portuguese | Formal Mozambican Portuguese |
|---|---|---|---|
| To access | acessar | aceder | aceder |
| Password | senha | palavra-passe | palavra-passe |
| Mobile phone | celular | telemóvel | telemóvel |
| File | arquivo | ficheiro | ficheiro |
| You | você | tu / você, depending on context | você / o senhor / a senhora, depending on context |
| With us | conosco | connosco | connosco |

## Reviewer Approach

1. Identify the intended audience when it is specified.
2. Preserve valid regional language when the audience is not specified.
3. Flag a form only when it is grammatically incorrect, unclear, inconsistent
   with the requested locale, or inappropriate for the context.
4. Explain corrections in a neutral and constructive way.
5. Avoid treating Brazilian Portuguese or European Portuguese vocabulary as
   automatically wrong.
