# Video, Data Annotation and Portuguese Language Review Portfolio

## About Me

I am an Information Technology student from Mozambique with an interest in
video annotation, data labeling, Portuguese language review, and quality
assurance for AI training projects.

My technical background includes Java, JavaScript, HTML5, CSS3, MySQL,
SQL Server, Git, GitHub, debugging, and database design. I am particularly
interested in structured annotation workflows, visual event analysis,
attention to detail, consistency, and clear documentation.

## Portfolio Sections

This section contains an independent practice exercise focused on identifying

Files:
